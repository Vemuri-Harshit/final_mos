Assumptions and how to read this

Assumptions

  1. Uniaxial loading along the muscle axis x. Only one stress component is non-zero:
    σ = diag(σₓₓ, 0, 0)
  2. Spindle-shaped muscle. The radius varies along the rest length l, with x measured from one end; c makes r = rmax at mid-length:
    r(x) = c · x (l − x),   c = 4 rmax / l²
  3. Constant volume (true stress). A muscle stretched by strain ε gets thinner, so the same force acts on a smaller area:
    σₓₓ = F (1 + ε) / (π r²)
  4. Same force through every cross-section. σₓₓ is therefore largest where the muscle is thinnest. It is evaluated at the cross-section through the plane's point P₀, which moves only along x and stays within 75% of the way from the centre to either end.
  5. σₓₓ is the average over the section. Using the Motor Unit Recruitment model, activated and unactivated fibres share it:
    σavg = f · σactive + (1 − f) · σinactive
    σinactive = σp(ε) = 3.1 (eε/0.12 − 1) kPa for ε > 0,  0 for ε ≤ 0
    σactive = (σavg − (1 − f) σp) / f,   at most σa(ε) = σp(ε) + 225 e−(ε/0.35)² kPa
    The toggle switches the tensor, traction and Mohr's circle between σavg, σactive and σinactive.
  6. Fibres only pull. Fibres carry tension only, so the activated-fibre stress is never taken below zero.
  7. The fascicles are only a drawing. They show where the plane cuts the muscle; they do not enter the calculation.

How to read this

  1. Traction on the plane. Because σ has only the xx entry, the traction always points along the muscle axis:
    t = σ · n = (σₓₓ nₓ, 0, 0),   |t| = σₓₓ |nₓ|
  2. Normal and shear parts.
    σₙ = σₓₓ nₓ²,   τ = σₓₓ |nₓ| √(1 − nₓ²)
    |t|² = σₙ² + τ²
    The last line says the point (σₙ, τ) lies on the Mohr circle. A plane parallel to the axis (nₓ = 0) carries no traction.
  3. Fascicle cuts. Cut fascicles show as ellipses, stretched when the plane is oblique to the axis. A plane nearly parallel to the axis shows them as strands lying in the plane.
  4. Scale. Arrow length is proportional to |t|: one tick along x is 0.5 MPa. The axis triad in the lower left follows the view.
